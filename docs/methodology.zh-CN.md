# 方法说明

[English](methodology.md) | **简体中文**

本文档定义图谱记录的内容及每个条目须遵循的规则，与 schema 同步版本化（当前为 schema 0.2），变更记录于 CHANGELOG。

## 1. 定义

**范式（Paradigm）**。对刺激、任务指令与时序的可复现描述，用于诱发可被记录和分析的脑活动。范式独立于任何单项研究而定义，研究和数据集是范式的实例。自 schema 0.2 起，图谱以两级记录范式（`curation/decisions.md` D-057）：

**范式类（Paradigm class）**。共享同一机制的一组具体范式：诱发相同的神经标记物、探测相同的认知构念，有共同的源头文献。范式类记录标记物、构念、该类的源头（`first_source`）与描述，登记在 `paradigms/_classes.yaml`，标识符为 `<范式族>-<简称>`（如 `MOT-MI`）。所诱发的标记物或所探测的构念改变，即为另一个范式类。范式类的 `first_source` 是该类中任一配置的、最早的、书目可识别的原始研究，不一定是 `-001` 的源头（`-001` 是标准配置，D-062）；范式类的 `markers` 是其具体范式标记物的并集（D-061）。

**具体范式（Concrete paradigm / protocol）**。范式类下一个可复现的任务配置，有自己的类别/条件集、提示与刺激、试次结构、反馈方式和数据集，标识符为 `<范式族>-<简称>-<序号>`（如 `MOT-MI-001` 左/右手二分类、`MOT-MI-002` 左手/右手/双脚/舌头四分类）。每个具体范式是 `paradigms/<范式族>/` 下的一个文件，`class` 字段指向其范式类，`protocol` 块写明配置要素以及它与同类其他具体范式的区别。给号规则见 §6。

**变体（Variant）**。只改变参数、不改变配置的做法：时长、刺激间隔、试次数、同一编码方案内的具体频率值、电极数或被试人群等。变体写在具体范式的 `variants` 或参数范围中，不分配新序号。改变类别/条件集、刺激或提示类型（含编码方案）、试次结构或反馈方式的，不是变体，而是新的具体范式（§6）。

**神经标记物（Neural marker）**。具有特征性表现的可测量脑活动特征，包括 ERP 成分、节律调制、稳态响应、血流动力学响应、单神经元或局部场电位模式。

**认知构念（Cognitive construct）**。标记物被认为所反映的心理过程或状态。若 Cognitive Atlas 中有对应概念，则建立映射。

**脑机接口类别**。参照 Zander 与 Kothe（2011）：*主动式*（用户有意产生控制信号，如运动想象）、*反应式*（信号由用户关注的外部刺激诱发，如 SSVEP、P300）、*被动式*（信号反映无需主动控制的内隐状态，如认知负荷、错误感知）。仅用于基础研究的范式记为 `none`。

## 2. 范围与纳入标准

范式须同时满足以下条件方可收录：

1. 曾在人类被试中使用 `taxonomy/recording_modality.yaml` 所列的至少一种记录模态采集脑活动。
2. 见于同行评议文献或公开预印本，且描述足以复现。
3. 至少诱发一种可在知识库中记录的神经标记物。

仅用于动物研究的范式不在 v1 范围内。满足上述条件的临床方案予以收录。

## 3. 出处规则

- 每一项内容均须引用文献，并尽可能提供持久标识符（DOI、PMID 或 arXiv 编号）。
- 出处须对照原始文献核实，不接受转引。
- 不推测任何标识符，无法核实的字段留空。
- 仅当维护者核实后，出处方可标记为 `verified: true`。
- 核实分两级（D-072）：**书目核实**指条目的书目字段与 Crossref、OpenAlex 或 PubMed 记录一致，结果记在 `curation/verification/sources_check.csv` 与 notes 固定短语 `bibliography confirmed|corrected (<API>, <date>)`；**内容核实**指对照原文全文确认该文献描述了该范式且是最早的，只有内容核实才能把 `verified` 设为 true。

## 4. 源头认定

`first_source` 记录首次以可辨识形式提出该范式的文献。若存在先驱工作或优先权有争议，应在 `notes` 中列出候选文献并简要说明理由。认定以已发表记录为准，有新证据时可修订。

## 5. 证据等级

每条“产生”（脑区 → 标记物）与“反映”（标记物 → 构念）关联均附等级：

| 等级 | 含义 |
|---|---|
| A | 有元分析或系统综述支持，或在独立实验室与多种模态中得到重复 |
| B | 有多项独立研究支持 |
| C | 仅有单项研究或间接证据支持 |
| D | 理论推测，尚未直接检验 |

等级描述的是已发表证据的强度，而非该关联的重要性。

## 6. 标识符

| 实体 | 格式 | 示例 |
|---|---|---|
| 范式类 | `<范式族>-<简称>` | `MOT-MI` |
| 具体范式 | `<范式族>-<简称>-<序号>` | `MOT-MI-001` |
| 神经标记物 | `MK.<名称>` | `MK.SMR_ERD` |
| 脑区 | `BR.<名称>` | `BR.visual_cortex` |
| 认知构念 | `CN.<名称>` | `CN.sustained_visual_attention` |

`<范式族>` 为 `taxonomy/families.yaml` 中的三字母前缀，`<简称>` 为 2–8 位大写字母或数字，`<序号>` 为三位数字。具体范式的 `class` 必须等于其 ID 去掉 `-<序号>`，且与范式类属于同一范式族。

**给号准则**。同一范式类下，以下任一项改变即分配新序号：

1. **类别/条件集**：解码或对比的类别、目标或条件的数量或身份。同质、可互换的目标集（SSVEP/c-VEP 键盘、P300 矩阵、扬声器或振动器位置）的目标个数是参数而非准则；加入或去掉静息/空闲/非控制类属于准则 1（D-058）；
2. **刺激或提示类型**：含刺激编码方案（如 SSVEP 的频率编码 vs 联合频率–相位编码；P300 的行/列闪烁 vs 棋盘格闪烁）；
3. **试次结构**：如同步（提示驱动）vs 异步（自定步调）；单试次 vs 组块；
4. **反馈方式**：无 / 离散 / 连续；开环 vs 闭环。

只改变参数（时长、刺激间隔、试次数、同一编码方案内的频率值等）的不给新号，作为变体记录（§1）。新具体范式的 `protocol.distinguishing` 须写明依据的准则编号。

**给号示例（运动想象，与 `paradigms/motor/` 中的文件一致）。**

| ID | 具体范式 | 依据 |
|---|---|---|
| `MOT-MI` | 范式类：提示性运动想象（MK.SMR_ERD；源头 Pfurtscheller & Neuper 1997） | — |
| `MOT-MI-001` | 左手 / 右手二分类，视觉提示，同步试次，无反馈 | 标准配置 |
| `MOT-MI-002` | 左手 / 右手 / 双脚 / 舌头四分类 | 准则 1 |
| `MOT-MI-003` | 单侧上肢 6 种动作（肘屈/伸、前臂旋后/旋前、手张开/握拳）+ 休息，共 7 类（Ofner et al. 2017） | 准则 1 |
| `MOT-MI-005` | 左/右手二分类 + 连续视觉反馈 | 准则 4 |
| `MOT-MI-009` | 异步（自定步调）运动想象，含空闲态 | 准则 3（另含准则 1） |
| `MOT-MI-011` | 单侧上肢 11 类动作想象（Jeong et al. 2020） | 准则 1 |

（勘误注，2026-10-03：决议 D-057 初稿的示例把 11 类写在 `MOT-MI-003` 下，与实际文件不符，已按 D-067 更正为上表。）

**永久性**。标识符永久有效。`-001` 为该范式类公认的标准配置（不一定最早发表；更早的兄弟配置在其 notes 中注明，并提供范式类源头，D-062），永不改号；其后的序号按认定顺序分配。所有标识符的含义自 v0.1.0 发布起冻结，此后的修正只能作废条目并给新号（D-063）。移除的条目标记为 `deprecated`，其标识符不再复用；被并入的候选 ID 也不复用。

## 7. 状态流转

`draft` → `reviewed` →（必要时）`deprecated`。当条目全部出处均已核实，且至少一位非贡献者本人的维护者批准后，状态改为 `reviewed`。

## 8. 版本管理

仓库遵循语义化版本。v1.0 之后，导致已有条目失效的 schema 变更将提升主版本号。每次发布都是图谱的一个可引用快照。
