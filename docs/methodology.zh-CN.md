# 方法说明

[English](methodology.md) | **简体中文**

本文档定义图谱记录的内容及每个条目须遵循的规则，与 schema 同步版本化，变更记录于 CHANGELOG。

## 1. 定义

**范式（Paradigm）。**对刺激、任务指令与时序的可复现描述，用于诱发可被记录和分析的脑活动。范式独立于任何单项研究而定义，研究和数据集是范式的实例。

**变体（Variant）。**保留范式核心逻辑的修改（例如改变刺激模态或呈现布局）。若修改改变了所诱发的标记物或所探测的构念，则视为独立的范式。

**神经标记物（Neural marker）。**具有特征性表现的可测量脑活动特征，包括 ERP 成分、节律调制、稳态响应、血流动力学响应、单神经元或局部场电位模式。

**认知构念（Cognitive construct）。**标记物被认为所反映的心理过程或状态。若 Cognitive Atlas 中有对应概念，则建立映射。

**脑机接口类别。**参照 Zander 与 Kothe（2011）：*主动式*（用户有意产生控制信号，如运动想象）、*反应式*（信号由用户关注的外部刺激诱发，如 SSVEP、P300）、*被动式*（信号反映无需主动控制的内隐状态，如认知负荷、错误感知）。仅用于基础研究的范式记为 `none`。

## 2. 范围与纳入标准

范式须同时满足以下条件方可收录：

1. 曾在人类被试中使用 `taxonomy/recording_modality.yaml` 所列的至少一种记录模态采集脑活动。
2. 见于同行评议文献或公开预印本，且描述足以复现。
3. 至少诱发一种可在知识库中记录的神经标记物。

仅用于动物研究的范式不在 v1 范围内。满足上述条件的临床方案予以收录。

## 3. 出处规则

- 每一项内容均须引用文献，并尽可能提供持久标识符（DOI、PMID 或 arXiv 编号）。
- 出处须对照原始文献核实，不接受转引。
- 不推测任何标识符，无法核实的字段留空。
- 仅当维护者核实后，出处方可标记为 `verified: true`。

## 4. 源头认定

`first_source` 记录首次以可辨识形式提出该范式的文献。若存在先驱工作或优先权有争议，应在 `notes` 中列出候选文献并简要说明理由。认定以已发表记录为准，有新证据时可修订。

## 5. 证据等级

每条“产生”（脑区 → 标记物）与“反映”（标记物 → 构念）关联均附等级：

| 等级 | 含义 |
|---|---|
| A | 有元分析或系统综述支持，或在独立实验室与多种模态中得到重复 |
| B | 有多项独立研究支持 |
| C | 仅有单项研究或间接证据支持 |
| D | 理论推测，尚未直接检验 |

等级描述的是已发表证据的强度，而非该关联的重要性。

## 6. 标识符

| 实体 | 格式 | 示例 |
|---|---|---|
| 范式 | `<范式族>-<简称>-<序号>` | `MOT-MI-001` |
| 神经标记物 | `MK.<名称>` | `MK.SMR_ERD` |
| 脑区 | `BR.<名称>` | `BR.visual_cortex` |
| 认知构念 | `CN.<名称>` | `CN.sustained_visual_attention` |

标识符永久有效。移除的条目标记为 `deprecated`，其标识符不再复用。

## 7. 状态流转

`draft` → `reviewed` →（必要时）`deprecated`。当条目全部出处均已核实，且至少一位非贡献者本人的维护者批准后，状态改为 `reviewed`。

## 8. 版本管理

仓库遵循语义化版本。v1.0 之后，导致已有条目失效的 schema 变更将提升主版本号。每次发布都是图谱的一个可引用快照。
