01 / 项目概览WHY THIS ATLAS EXISTS

从分散的实验，
到相连的知识。

BCI Paradigm Atlas
脑机接口范式及其神经基础的开放图谱。

脑机实验从刺激、任务与时序开始。图谱整理“用什么任务诱发什么信号”，并进一步关联信号的神经来源和认知含义，由思维刻度 SavorCode 发起并维护。

项目回应三个问题：范式与别名散落在文献中，神经机制的假设常被省略，研究覆盖集中在少数常用任务上。统一的条目、标识符和证据规则，让这些知识可以检索、比较和复用。

范式目录记录具体实验协议；神经知识库记录标记物、脑区和认知构念。两层通过明确的关系相连，形成可导出的知识图谱。

结构化可追溯可引用

04 / 如何使用READ, VALIDATE, EXPORT

从查阅协议，
到使用整张图。

研究者可以沿范式查证据，开发者可以读取结构化数据。
所有数据与工具都在同一个公开仓库中。

01

找到任务与协议

在 paradigms/ 中按范式族查阅 YAML 条目，比较条件集、刺激与提示、试次结构和反馈；通过 class 回到共同机制，通过 markers 进入神经知识。

打开范式目录 ↗
02

校验数据，再导出图谱

下载或克隆仓库后，在仓库根目录安装依赖、运行校验与导出工具。导出的 dist/graph.json 含 nodes 和 edges，可用于图计算或图数据库。

pip install -r scripts/requirements.txt
python scripts/validate.py
python scripts/build_graph.py
查看导出工具 ↗
03

带着版本与证据使用

引用时注明图谱版本、条目标识符与 draft 状态，并追溯条目中的原始文献。图谱文件提供关系与等级，完整出处和核查状态保留在源条目中。

05 / 证据与当前状态WHAT THE EVIDENCE MEANS

知道关联，
也知道依据。

A–D 描述已发表证据的强度。
等级与条目的审核状态是两个维度。

A

综合与重复证据

有元分析、系统综述支持，或在独立实验室与多种模态中得到重复。

B

多项独立研究

关联获得多项独立研究的支持。

C

单项或间接证据

目前仅有单项研究，或通过间接证据支持。

D

理论推测

提出了关联假设，尚未得到直接检验。
